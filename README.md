# silica-brand

Il marchio di [Silica](https://github.com/silica-linux/silica-desktop): il logo (con il nome in
Inter), le sue varianti per avvio, login e «Info», i banner dei repository e gli sfondi delle
versioni. Ogni file ha la sua riga in `ASSETS.md` (autore, licenza, fonte).

Regole clean-room come per silica-icons: nessuna forma che richiami marchi di altri sistemi.
La licenza del logo è da decidere (un marchio di solito non è riusabile liberamente).
